## Cybersecurity Zero Trust Tactics

**[Zombie Card Attack Can Revive Expired Visa Cards for Contactless Payments](https://thehackernews.com/2026/08/zombie-card-attack-can-revive-expired.html)** (Hacker News, citing University of Massachusetts Amherst researchers) — Researchers Raja Hasnain Anwar, Gerard DeCunha, and Muhammad Taqi Raza found a gap in Visa's Kernel 3 contactless implementation: a card's expiration date appears twice in a transaction (once in the Application Expiration Date tag, again in Track 2 Equivalent Data), but the fast Dynamic Data Authentication signature the terminal checks excludes the first of those two fields entirely. A man-in-the-middle relay can rewrite the terminal-facing expiration date to any future value while leaving Track 2 untouched, letting an expired card's signature validate normally. Testing against five major U.S. banks produced mixed results — one bank approved the revived transaction, one declined it outright, and a third's EMV kernel rejected the tampering — while Mastercard, American Express, and Discover kernels all included protections Visa's lacked. Visa received disclosure in May and December 2025; as of this month, no CVE has been assigned and no public advisory has been issued by Visa, EMVCo, or any terminal vendor.

**[Elementor Pro Flaw Could Let Unauthenticated Attackers Upload PHP and Execute Code](https://thehackernews.com/2026/08/elementor-pro-flaw-could-let.html)** (Hacker News) — A critical flaw in the popular WordPress page-builder plugin's Forms module (CVE-2026-32475, CVSS 9.0) let unauthenticated attackers bypass file-extension validation and upload PHP files to public directories, achieving remote code execution. The bug stems from the extension check and the file-move step running in two separate loops with different handling of empty file entries, letting an attacker submit dual file parts for a single upload field and slip past the blocklist entirely. Security researcher Tin Pham (TF1T) reported it through Patchstack's bug bounty program on July 16th; Elementor shipped a fix in version 4.2.2 on August 19th. No active exploitation has been reported, and all versions through 4.2.1 are affected.

**[943 Patches Rolled Out With Oracle's August 2026 Security Update](https://www.securityweek.com/943-patches-rolled-out-with-oracles-august-2026-security-update/)** (SecurityWeek, via a Gmail digest) — Oracle's August Critical Patch Update addresses 925 unique CVEs across 943 individual patches spanning 23 product families — roughly four times the patch volume of June's update. More than 460 of the flaws are remotely exploitable without authentication, and nearly 90 carry a CVSS score of 9.8 or higher. Fusion Middleware and Hyperion each received the largest share of new patches (262 apiece, including over 100 combined critical-severity fixes), and the release includes several WebLogic Server vulnerabilities that could let an unauthenticated remote attacker take full control of an affected server.

**[CDN Tsunami Attack Abuses HTTP/3 Translation for Up to 350x DoS Amplification](https://thehackernews.com/2026/08/cdn-tsunami-attack-abuses-http3.html)** (Hacker News, citing researchers from the National University of Singapore, Fuzhou University, University of Sheffield, and Johns Hopkins University) — Two related techniques exploit how content delivery networks translate client-facing HTTP/3 traffic into HTTP/1.1 requests toward origin servers. "HTTP/3 Bandwidth Amplification" abuses QPACK header compression — since HTTP/1.1 has no equivalent, CDNs must expand small compressed values into full headers before forwarding, letting minimal attacker bandwidth consume disproportionate origin resources. "HTTP/3 Connection Amplification" exploits CDNs opening backend HTTP/1.1 connections as soon as HEADERS frames arrive, before the DATA payload — HTTP/3 multiplexing lets a single client connection trigger multiple backend TCP connections that stay open while data trickles in slowly. All six tested providers — Alibaba, Baidu, Cloudflare, Amazon CloudFront, Fastly, and Tencent — were susceptible, with amplification peaking at 350x on Alibaba, Baidu, and Tencent's dynamic QPACK tables (CloudFront: 51.2x, Cloudflare: 48.27x, Fastly: 36.41x). No CVE has been assigned and no wild exploitation has been reported; Baidu and Tencent have deployed mitigations.

**[NASA AIT-GUI Flaws Could Let Unauthenticated Attackers Issue Spacecraft Commands](https://thehackernews.com/2026/08/nasa-ait-gui-flaws-could-let.html)** (Hacker News, citing Cycode) — NASA/JPL's browser-based spacecraft command console, AIT-GUI, shipped with missing authentication on state-changing endpoints, no CSRF protection, path-traversal flaws in its script and sequence handlers, and a server that binds to all network interfaces by default instead of localhost (GHSA-p9r8-2q67-fp86, CVSS 9.4; CVE-2026-60112, CVSS 9.3, both affecting versions 2.5.1 and earlier). Cycode researchers confirmed unauthenticated attackers could issue arbitrary instrument and spacecraft commands via a POST endpoint and execute server-side scripts through the path-traversal bug. Version 2.5.2, released August 12th, binds to the configured host, adds same-origin checks, and confines file operations to intended directories — but notably does not add authentication to the command endpoints themselves. The fix commit credits Anthropic's Claude Opus 4.8 as a co-author alongside the human researcher.

## Adversary Playbook

**[ToxicPanda 2.0 and GoldDigger Expand Android Banking Attacks with On-Device Fraud](https://thehackernews.com/2026/08/toxicpanda-20-and-golddigger-expand.html)** (Hacker News, citing Zimperium zLabs and IBM Trusteer) — Two established Android banking-trojan families received fresh reporting on active campaigns. ToxicPanda 2.0, active since at least 2022, now carries 167 remote commands and targets 140+ banking and cryptocurrency apps; per Zimperium, it abuses Android accessibility services for on-screen credential theft, deploys overlay attacks against 349 financial institutions across 16 countries, harvests lock-screen PINs, and exploits Wireless Debugging via ADB for privilege escalation, distributed through Amazon AWS-hosted buckets. GoldDigger, documented since October 2023 and attributed to the Chinese-speaking threat actor GoldFactory (also linked to the GoldPickaxe and GoldDiggerPlus malware families), injects fake overlays and simulated taps directly into banking apps to conduct fraudulent transactions in real time, currently targeting South Africa and the UK via airline- and retailer-impersonation lures. Both rows are added to the Adversary Tracking Report as Cybercrime, Tier 2 — GoldFactory's language-based profile is not a state-sponsorship claim.

**[Manic Android Malware Exfiltrates Data From Offline Phones via Nearby Infected Devices](https://thehackernews.com/2026/08/manic-android-malware-exfiltrates-data.html)** (Hacker News, citing ThreatFabric) — Manic combines Android banking-fraud capabilities with mobile spyware, and introduces a novel store-and-forward relay: it stages encrypted files in a local queue, then searches for nearby infected devices over Wi-Fi Direct, Bluetooth RFCOMM, or BLE GATT to relay stolen data toward command-and-control infrastructure — up to four hops by default — letting it exfiltrate from a device with no active internet connection. ThreatFabric has tracked the malware since February 2026; it monitors 169 package IDs, concentrated on Ukrainian banks, government services, and messaging apps, alongside Russian and European financial institutions, global fintech/crypto services, and military-focused communications platforms. No nation-state or organized-group attribution has been offered. Added to the Adversary Tracking Report as Unclear rather than Cybercrime — the mix of financially-motivated fraud tooling with surveillance of government and military communications platforms doesn't resolve into a single Crime or Espionage motivation on the reporting available, and no state sponsorship is asserted.

**[40 Malicious Firefox Extensions Pose as Web3 Products to Steal Wallet Secrets](https://thehackernews.com/2026/08/40-malicious-firefox-extensions-pose-as.html)** (Hacker News, citing Socket Threat Research) — A campaign dubbed "Offside Wallet Theft Factory," active since March 2026, ran 77 malicious Firefox add-ons impersonating legitimate Web3 products including OKX, Rabby Wallet, and TronLink; researcher Kirill Boychenko and Socket's team confirmed 40 of them as directly malicious. Seven use threat-actor-controlled Supabase projects to dynamically serve phishing content; fifteen capture recovery phrases and private keys and exfiltrate them via Cloudflare Workers; thirteen are modified Rabby Wallet builds that steal encrypted keyrings; five capture credentials and clipboard data through hardcoded C2 infrastructure. Some extensions launched as innocuous sports-score or utility tools before being repurposed as wallet-stealers under the same Firefox extension IDs. Mozilla's removal status was not specified in the reporting. Added to the Adversary Tracking Report as Cybercrime, Tier 3 (unattributed operator).

## Cybersecurity Automation Tactics

**[Why "Shady AI" Is Security's Next Big Governance Problem](https://thehackernews.com/2026/08/why-shady-ai-is-securitys-next-big.html)** (Hacker News, featuring Tines) — The piece distinguishes "shadow AI" (unapproved tools) from "shady AI" — employees using company-*approved* AI tools in unapproved or unexpected ways, illustrated by an incident in which an authorized AI agent posted sensitive data publicly without approval. A July 2026 SANS survey found 76% of security teams now hold some role in governing enterprise AI, but the article argues traditional governance fails here because policies can't anticipate evolving capabilities and one-time training can't keep pace with constantly changing features — restrictions tend to produce workarounds rather than solve the underlying problem. Its proposed fix is "governance by default": embedding permissions and oversight directly into the environment where employees build AI applications, so the governed path is also the easiest one.
