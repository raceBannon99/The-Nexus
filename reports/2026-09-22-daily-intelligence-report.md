## Adversary Playbook

**A new tool found malware guided by an AI hive mind — no human operator at all.** Cisco Talos released [CAIRN](https://www.wired.com/story/a-tool-for-tracking-ai-integrated-malware-uncovered-an-autonomous-command-system/) (Cognitive Artifact Intelligence Research Network), an open-source framework for fingerprinting AI-integrated malware, and immediately used it to identify CLOSEDQUORUM — Windows malware whose command-and-control is fully autonomous. Rather than a human operator or a hardcoded C2 server, the implant polls up to four large language models (DeepSeek, Qwen, Mistral, Google Gemini) and takes its next action from whichever consensus emerges; redundancy across all four means there is no single point of human input at any stage. Talos researcher Ryan Fetterman built CAIRN after finding that a year of retrospective research on AI-integrated malware had turned up only about nine documented families — far fewer than expected — and CAIRN has already surfaced roughly 20 more previously undocumented samples. CLOSEDQUORUM itself shows some links to 2025-era credit-card-fraud forum activity and is designed to steal login credentials and cryptocurrency, but Talos could not confirm who built it or whether it has been used in a real intrusion. Added to the Adversary Tracking Report as Unclear row 46, tagged 🤖 — the table's first row where an autonomous AI agent *is* the C2 infrastructure, not merely a tool assisting a human-directed attack. This item also runs below under **AI Singularity Timeline**, since it bears directly on how far no-human-in-the-loop decision-making has diffused into off-the-shelf criminal tooling.

**China's Red Heron campaign widens to Zyxel switches and a Veeam privilege-escalation flaw.** [Zyxel and Veeam Flaws Under Active Exploitation With Command and SYSTEM Access](https://thehackernews.com/) (The Hacker News) reports a suspected Chinese-speaking actor has, since Aug. 17, mass-exploited CVE-2026-7273 — a stack-based buffer overflow in Zyxel GS1900-series switches (CVSS 8.8) — compromising 996 switches across 48 countries including Italy, the US, Taiwan, France, and South Korea, using a heavily obfuscated PyArmor-packed Python script to pull configuration data and hashed root credentials via TFTP. Separately, Arctic Wolf reports active exploitation of CVE-2026-32996, a local-privilege-escalation flaw in Veeam Agent for Windows, via credential theft from readable log files. Both campaigns overlap activity Acronis tracks as "Red Heron" — already tracked in this table as China row 24 (the Gitea RCE mass-exploitation campaign) — so both are folded into that existing row rather than treated as new campaigns. Confirmed via CISA's Sept. 21 Known Exploited Vulnerabilities catalog addition for CVE-2026-7273, cross-referenced here per that source's own primary-source convention.

**Pakistan's second-ever row: SideCopy broadens from government to academic targets in India.** [SideCopy Broadens India Targeting to Academia With ReverseRAT Spear-Phishing](https://thehackernews.com/) (The Hacker News) reports SideCopy (TAG-140), a Pakistan-based group per SEQRITE Labs that overlaps the Transparent Tribe cluster added to this table's Pakistan column just yesterday, has expanded its long-running ReverseRAT implant (in use since 2021) beyond its historical defense-and-government targeting into Indian academic institutions. The campaign delivers ZIP archives containing malicious .LNK files disguised as PDFs, which execute obfuscated HTML applications via `mshta.exe`; ReverseRAT then harvests system metadata, installed software, screenshots, passwords, and clipboard content, and sets up Registry persistence. C2 runs through `dns.educationportals[.]biz`. Added as Pakistan row 2, Tier 2.

**A hedged North Korea-overlap social-engineering campaign targets Rust maintainers.** [Fake LastPass Authenticator Installer Abuses Microsoft-Signed Driver to Kill Antivirus and EDR](https://thehackernews.com/) and a companion [SecurityWeek report](https://www.securityweek.com/rust-team-members-and-popular-crate-owners-targeted-via-video-calls/) describe attackers posing as recruiters, luring Rust-lang team members and popular crate maintainers into video calls, then either claiming a missing audio codec requires installing attacker software or asking targets to paste malicious code to their clipboard — all backed by fake company LinkedIn pages. The Rust Foundation's own team notes North Korea "is known to use this style of attack" and flags a technique overlap with an August incident involving the `arrayref` crate already linked to North Korean actors, but explicitly does not assert this is the same campaign or state-directed. Added as Unclear row 47, Tier 3.

**A new "Rapuncel" fake-LastPass installer kills 145 security products from the kernel.** [Fake LastPass Installers Push Kernel-Level EDR Killer, 'Rapuncel' Stealer](https://www.securityweek.com/) reports LastPass and Delphos Labs jointly analyzed a trojanized GitHub repository impersonating LastPass's authenticator (and at least 40 other software brands). The installer bundles a legitimate Microsoft debugging tool (`vsdbg.exe`) with a malicious DLL for side-loading, which installs a kernel-level driver — Alinubx.sys, a renamed but still Microsoft-signed `CcProtect.sys` from the Chinese CnCrypt encryption product — that terminates 145 antivirus/EDR processes from kernel level before deploying a password stealer. Researchers assess with high confidence the loader uses the Cruciferra crypter (already seen in this table's TA4922/Operation DragonReturn China row) and with moderate confidence that the stealer is a relative of BoryptGrab. No actor named. Added as Cybercrime row 66, Tier 3.

**Malicious npm package "indexed-btree" hid its loader in runtime code, not an install script.** [Malicious npm Package Accumulates Millions of Downloads](https://www.securityweek.com/) reports "indexed-btree," which impersonated the legitimate `sorted-btree` library, was uploaded June 18, 2026 by publisher handle "charlessadler25" and accumulated millions of downloads before removal. Unlike typical supply-chain attacks that rely on preinstall/postinstall scripts, this package embedded its loader directly in the runtime `BTree.prototype.set()` method, triggering an obfuscated payload that fingerprints the host, beacons to hardcoded Slack and Telegram channels, and uses EtherHiding — retrieving an encrypted payload from a smart contract on the Sepolia testnet — to assemble a second-stage payload. At least 10 related packages tied to the same operation were also removed; the operator netted roughly 109 ETH (~€230,934). Added as Cybercrime row 68, Tier 3.

**ShinyHunters hijacks rival gang Cl0p's own leak site and starts extorting Cl0p directly.** [ShinyHunters cybercrime gang takes over Cl0p ransomware site, demands extortion payment](https://therecord.media/shinyhunters-clop-cyberattack-website) reports the ShinyHunters extortion group — already tracked in this table's Cybercrime row 20 — defaced Cl0p's dark-web leak site over the weekend, posting an unspecified eight-figure extortion demand described as "2.333%" of ShinyHunters' own claimed net worth, plus a threat to publish records of which Cl0p victims paid, how much, and to which Bitcoin addresses. The message named three alleged Cl0p operators (all previously named in public reporting) and demanded proceeds from Cl0p's recent Oracle E-Business Suite extortion campaign, which followed ShinyHunters' own public release of a proof-of-concept exploit for the underlying Oracle flaw — the two groups' feud reportedly stems from Cl0p's unauthorized use of that exploit and threats against a ShinyHunters member. Cl0p (Cybercrime row 19) posted a reply Monday asking to be contacted through "the old platform." A rare instance of one tracked cybercrime group directly extorting another already in this table; folded into both existing rows rather than treated as new.

**"Venus1337" claims breaches of two Belgian sports federations.** [Belgian table tennis, gymnastics federations hit by cyberattacks](https://therecord.media/belgium-table-tennis-cyberattack) reports a hacker using the handle "Venus1337" claims to have breached Belgium's French-speaking Gymnastics Federation (FfG, which has confirmed unauthorized access to part of its IT environment) and the Royal Belgian/French-speaking Table Tennis Federations (FRBTT/AFTT, still investigating). Venus1337 claims roughly 1.7GB from the table tennis federations (66,800+ members, 17,400+ users) and 200,000+ members' records from the gymnastics federation, including coaching/judging-license data and accident-report data; neither federation has independently verified the attacker's own figures. Part of a wider pattern of 30+ French sports-federation breaches since late 2025, with no confirmed link between incidents. Added as Cybercrime row 67, Tier 2.

**Russia claims thousands of DDoS waves against its own election infrastructure — unverified, blamed on Ukraine, the UK, Brazil, and Mexico.** [Russia reports thousands of cyberattacks on election infrastructure during vote](https://therecord.media/russia-reports-cyberattacks-during-election) reports Russian officials claim roughly 3,000+ waves of DDoS and other attacks against the federal online-voting platform (Vybory 2.0), the Central Election Commission's website, e-government infrastructure, and telecom operator Rostelecom during the Sept. 18-21 State Duma election, plus alleged deliberate fiber-optic-cable sabotage in the Far East. CEC Chair Ella Pamfilova said attacks originated primarily from the UK, Ukraine, Brazil, and Mexico, but the Kremlin offered little public evidence for any of these attributions, and the claims cannot be independently verified. Separately, the hacktivist group CikLeak — already tracked in this table's Hacktivism section — had claimed a pre-election breach of Russia's CEC and Vybory-contractor systems, urging Russians to vote in person rather than trying to disrupt the vote itself. Officials reported no successful compromise of vote counts; the ruling United Russia party won roughly 57.8% of the party-list vote. Added as Unclear row 48, Tier 3.

## Zero Trust Tactics

**A SharePoint flaw Microsoft first called "spoofing" actually enables authenticated remote code execution.** [SharePoint Flaw Initially Listed as Spoofing by Microsoft Enables Authenticated RCE](https://thehackernews.com/) reports CVE-2026-65660 (SharePoint Server 2016, 2019, and Subscription Edition) exploits improper quote escaping in the ToolPane component's web-part markup processing, letting an authenticated attacker register arbitrary .NET classes and trigger code execution via `XamlServices.Parse()` deserialization. Microsoft rated it CVSS 6.5 (spoofing); the researcher who found it and NVD both rate the actual impact at CVSS 8.8. No exploitation has been reported in the wild and the flaw isn't in CISA's KEV catalog, though the researcher notes Chinese state-backed groups have previously exploited related SharePoint flaws. Patched since Aug. 11.

**A WordPress comment-sanitization gap can escalate anonymous XSS to admin-level RCE.** [WordPress Comment2Shell Flaw Can Turn Anonymous Comment XSS Into RCE via Admin Session](https://thehackernews.com/) reports CVE-2026-93485 ("Comment2Shell," WordPress core 4.7-7.1) lets an anonymous commenter inject a script by placing a line break inside an HTML tag attribute; WordPress's comment-reformatting logic then moves the malicious text into an event-handler position, so the script executes automatically when a logged-in administrator views the page. No known exploitation; patched Sept. 17 across the 7.1.1, 7.0.5, 6.9.8, and earlier branches back to 4.7.36.

**Three actively-exploited Linux kernel flaws added to CISA's KEV catalog.** SecurityWeek's [Organizations Warned of 3 Exploited Linux Kernel Vulnerabilities](https://www.securityweek.com/) and a corresponding CISA KEV catalog addition (Sept. 21) cover CVE-2025-39682 (CVSS 9.8, TLS zero-length-record handling, denial-of-service/memory disclosure), CVE-2025-39964 (CVSS 7.8, an AF_ALG socket race condition), and CVE-2026-53266 (CVSS 8.8, an out-of-bounds write in bridge Netfilter ebtables SNAT via crafted ARP packets). CISA has not disclosed exploitation details or attributed the flaws to any actor; federal agencies were given three days to patch.

## Superintelligence Timeline

**Superintelligence Timeline: P5 2029 · P50 2045 · P95 2100 (structural inference, no external forecaster basket — unchanged since 2026-09-18).**

**RAND proposes a "Freedom of Action" strategy for the path to superintelligence.** [Import AI 473](https://importai.substack.com/p/import-ai-473-the-uss-superintelligence) covers RAND's new paper, "A U.S. Strategy to Secure Geopolitical Advantage on an Uncertain Path to Superintelligence," which argues the US should invest now to preserve future policy options rather than commit to one path, given five deep uncertainties: how close the danger actually is, whether humans and advanced AI can reach stable coexistence, whether cooperative restraint is achievable, whether one actor can lock in a lasting advantage, and whether rival programs can actually be suppressed. RAND catalogs seven strategy archetypes — Dominance, Co-Development, and Preparedness under "Coexistence"; Moratorium, Deterrence, and Continuity of Society under "Denial"; and Acceleration — and assesses current US posture as closest to Acceleration, investing heavily in capability with comparatively little in proactive safety measures. RAND offers no probability or date estimate of its own. Seldon logs this as Ambiguous: it sharpens the strategic stakes of treating superintelligence as distinct from AGI arrival — corroborating this file's own Definitions section — but supplies no new evidence about the transition gap's actual length. **Cross-ref:** [[First Principles Newsletter Tracker]] → Thread 5, which the paper's own competitive-advantage framing Complicates.

**Toby Ord models hard limits on how fast a recursive-self-improvement explosion could actually go.** The same newsletter covers philosopher Toby Ord's "The Dynamics of Intelligence Explosions," which argues that generation time — how long it takes to design and train the next model generation — cannot approach zero, providing "an important kind of barrier to singular growth." Ord identifies five independent hard limits an RSI process would run into (intelligence itself, intelligence per unit resource, hardware, algorithms, and training data) and proposes a four-phase model running from human-only exponential growth through a super-exponential RSI phase to eventual saturation and a logistic plateau — not an unbounded exponential. Ord's own caveat: even a bounded, eventually-saturating process could still compress a decade of human-only progress into a year, which he argues is dangerous regardless of the curve's ultimate shape. Seldon logs this as Later-leaning bottleneck evidence — the most rigorous treatment yet of the reasoning already behind this file's 9-year AGI-to-superintelligence gap assumption, reinforcing rather than shifting the current P50.

## Automation Tactics

**A hidden Meta Muse setting could turn the AI assistant into a backdoor.** [One Hidden Meta Muse Setting Could Let Attackers Turn the AI Assistant Into a Backdoor](https://thehackernews.com/) reports security researcher Patrick Wardle found that Meta's Muse assistant for Mac exposes a hidden setting (`endo_voyager_dictation_endpoint`) that any program already running as the logged-in user can modify without extra permissions — redirecting Muse's voice-dictation audio and text to an attacker-controlled server instead of Meta's own. Wardle describes a "ClickFix"-style path to the initial compromise: tricking a user into running a terminal command requires nothing to download or install. No evidence of active exploitation; Meta has pushed an unconfirmed "fix," but has not published a security advisory.
