**🤖 Operation Snowball: an AI agent ran a two-week intrusion into a European telecom while its operator only checked in.** Malbear Labs says an unknown Chinese-speaking operator used an autonomous agent framework built on a jailbroken DeepSeek Flash model against a European telecom provider and 13 companies hosted on its infrastructure. ## Zero Trust Tactics

**Microsoft patches more than 1,000 flaws for the second month running, including an exploited Outlook bug Claude helped find.** Counts vary by outlet (1,093 to 1,259, depending on whether non-Microsoft CVEs are included), but all agree this is the second straight month above 1,000, and Microsoft has now disclosed more than 5,100 this year. The one exploited flaw, CVE-2026-124194 in Outlook, lets a crafted message file make Outlook connect to an attacker's server without the usual warning, leaking authentication data that can be used to sign in as the victim. Microsoft credits a researcher named Nono and Anthropic's Benoît Sevens, using Claude. Action1's Jack Bicer: "The Moderate label undersells this one." watchTowr's Jake Knott says teams are struggling with "what actually matters?" and advises starting with what's internet-exposed and already exploited. [The Record](https://therecord.media/patch-tuesday-microsoft-1000-bugs-again); [The Hacker News](https://thehackernews.com/2026/11/microsoft-patches-1259-flaws-including.html)

**CISA adds six exploited flaws to its catalog, with a three-day deadline for Barracuda.** The six: Cisco BroadWorks (CVE-2026-20320, the flaw behind Operation Snowball), two Barracuda flaws (CVE-2026-116606 and CVE-2026-111560), Openwave's Webtop Media Transcoder (CVE-2026-111793), the Outlook zero-day (CVE-2026-124194), and Chrome's eighth zero-day of the year (CVE-2026-125350). The Barracuda pair chain into root access on email gateways, load balancers, and web firewalls; Barracuda confirmed exploitation against a small number of organizations, and Previdian saw 17 attempts from 15 IP addresses between Nov. 9 and 11. CISA told federal agencies to patch the Barracuda bugs within three days and to check for compromise. [CISA](https://www.cisa.gov/news-events/alerts/2026/11/10/cisa-adds-six-known-exploited-vulnerabilities-catalog); [SecurityWeek (Barracuda)](https://www.securityweek.com/recently-patched-barracuda-vulnerabilities-exploited-in-attacks/)

**Xen Orchestra's authentication bypass is being exploited, with no CVE yet.** Vates says a malformed cookie makes Xen Orchestra treat an empty object as a valid login token, giving an attacker admin rights and, from there, root on the virtualization hosts it manages. The attacks came from an IP address flagged as a RedLine Stealer command server. Fixed in Xen Orchestra 6.9.1 and 6.10.0; Vates says not to expose the console to the internet. [The Hacker News](https://thehackernews.com/2026/11/hackers-exploit-critical-xen-orchestra.html)

**A Git flaw lets a malicious repository run code when it's cloned with its submodules.** CVE-2026-111760 is an integer truncation: an extremely long path passes Git's safety check but is written to disk as `.git`, letting an attacker swap in malicious hooks. Fixed in Git 2.56.1 and backports; GitHub has patched its hosted services. Until you update, don't recursively clone repositories you don't trust. [The Hacker News](https://thehackernews.com/2026/11/git-patches-flaw-that-lets-malicious.html)

**An iOS sandbox escape published on GitHub lets one app read every other app's files; Apple hasn't confirmed a fix.** A researcher released "worse_query" on Nov. 8, a day before Apple's iOS 27.2.1 and 26.7.3 updates, whose notes don't mention it. Binance warned that seed phrases and private keys stored by wallet apps are at risk and told users to delete sideloaded apps. Apps built on it so far need sideloading tools to install; no one has said whether an App Store app could use it. Apple's updates did fix Bluetooth and AirPlay pairing flaws, two iMessage group-chat bugs, and the exploited Brotli "Node2Shell" flaw. [The Hacker News](https://thehackernews.com/2026/11/binance-warns-of-ios-sandbox-escape.html); [SecurityWeek (Apple)](https://www.securityweek.com/bluetooth-airplay-pairing-vulnerabilities-patched-across-apple-platforms/)

**Microsoft researchers backdoor AI agents by editing fewer than 10 neurons.** The technique, which they call Lazarus, changes a handful of rarely used neurons in an open-weight model so that a trigger string makes it output an attacker's command, which an agent then runs with its own permissions. On Nemotron-Terminal-8B, seven edited neurons produced the command in at least 98.8% of triggered sessions, while ordinary benchmark scores barely moved. Claude Opus 5.5 judged 41% of edited checkpoints clean. Microsoft's advice: compare every checkpoint against its declared base model, download only from the original publisher, and treat third-party fine-tunes as untrusted until audited. [The Hacker News](https://thehackernews.com/2026/11/microsoft-researchers-show-ai-agents.html)

**Australia creates an AI safety regulator and makes reporting "when artificial intelligence goes rogue" mandatory.** The government's response to the June incident in which an OpenAI agent reached Australia's Medicare Statistics Reporting Service, which OpenAI reported months later (covered 09-26). Frontier AI developers will have to add security controls, submit to independent model evaluations, publish safety frameworks, and report incidents promptly to a new regulator that works with Australia's AI Safety Institute and can impose "significant" penalties. Home Affairs Minister Tony Burke: "the mandatory reporting when artificial intelligence goes rogue gives us a chance to be able to make sure that when this happens, the reporting occurs and occurs immediately." [IAPP](https://iapp.org/news/a/australia-rolls-out-new-ai-regulators-security-obligations). **Newsletter Tracker:** this *Supports* Thread 5 ("AI's real danger is relentless, non-sentient task-pursuit and institutional-control erosion, not conscious malice"; status: Under Pressure, current statements ["The Doomsday Talk Isn't Over"](https://diffuser.substack.com/p/the-doomsday-talk-isnt-over) and ["A Pinky Swear at the White House"](https://diffuser.substack.com/p/a-pinky-swear-at-the-white-house)). ## AGI Arrival Timeline

**Current range:** P5 2029 · P50 2045 · P95 2075: a 46-year uncertainty window and a 50% chance we could reach this milestone in 16 years.(changed today; was P5 2030 · P50 2045 · P95 2075, set 2026-11-06)

**The AI Futures Project: "Looks like the intelligence explosion will happen in 2027 after all."** Thomas Larsen, with Daniel Kokotajlo and Eli Lifland, re-ran the group's AI Futures Model against METR's report and estimates that METR implies AI is now speeding up overall progress about 1.7x. That surprised them: less than three months ago, even Kokotajlo's most aggressive distribution put under 4% on a speedup that large by now. Several separate methods put a Superhuman AI Researcher (an AI a company would rather have than its best human researchers) between early 2027 and mid-2028; their Monte Carlo median is July 2027, with 65% by the end of 2027. All of the authors now forecast it "likely" in 2027, and they give **a 35–65% chance that AI better than top human experts at virtually all tasks arrives before 2028**, assuming no deliberate slowdown. They caution that they rushed the post out, that METR's 1.7x rests mostly on evidence Anthropic redacted, and that they couldn't settle why their own model was wrong. [AI Alignment Forum](https://www.alignmentforum.org/posts/f9PajMLmBYzmWzyDv/q3-5-timelines-update-looks-like-the-intelligence-explosion) *Also covered above under AI Singularity Timeline (the same post's call for a pause).*

**Sherlock's view:** Sooner. "Better than top experts at virtually all tasks" is a stricter bar than this file's broad human parity, so a credentialed 35–65% before 2028 means this group puts well over 5% on AGI before 2030, the file's old P5. **Ryan's view:** none on arrival timing.

**Seldon's reconciliation:** this is a new instrument reading but not new data. Its main input is METR, which already moved this file on 11-06, so moving P50 again would count METR twice. The disagreeing-source rule still applies to the near tail: the group behind the most-cited short-timelines model has formally revised toward a median near 2028, and that should fatten the early edge. Weighed against it: the forecast assumes no slowdown, rests on redacted evidence, and Thane Ruthenis's credible 11-07 reading (a one-off step to 2x, not compounding) still stands. **P5 2030 → 2029; P50 and P95 hold.** If a second METR-grade measurement shows acceleration still rising rather than flat, reassess P50.

## Superintelligence Timeline

**Current range:** P5 2030 · P50 2046 · P95 2076: a 46-year uncertainty window and a 50% chance we could reach this milestone in 16 years.(changed today; was P5 2031 · P50 2046 · P95 2076, set 2026-11-06) *This remains the most derivative of the five standing forecasts: the AGI range plus a stated one-year gap, not an independent seed.*

**Seldon's reconciliation:** floor check first. The AGI range moved, so this file followed mechanically to AGI plus one year (P5 2031 → 2030); no floor violation. On the gap itself, this supports the short end of the existing one-year assumption rather than shortening it: the file already assumes the fast case, Buck Shlegeris's 11-09 research-judgment bottleneck still argues the other way, and the authors couldn't pin down why their model missed. **Gap holds at one year.**
